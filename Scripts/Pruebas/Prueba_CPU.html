Cómo se hace

  • Cálculo verificado: cada hilo repite cuentas enteras y de coma flotante cuyo resultado se conoce de antemano. Un resultado distinto es un error de cálculo: suele indicar inestabilidad (overclock, voltaje bajo, refrigeración justa o procesador dañado).
  • Puntuación: millones de operaciones por segundo entre todos los hilos. Sirve para comparar el mismo equipo antes y después de un cambio (pasta térmica, BIOS, limpieza); no para compararlo con otros equipos.
  • Caída de rendimiento: si al final rinde bastante menos que al principio, el procesador está reduciendo velocidad por calor.
  • Regla de oro: si la prueba no se pudo hacer o se detuvo, es «No evaluado», nunca «Falla».
