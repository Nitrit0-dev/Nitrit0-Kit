# Herramientas de terceros

Nitrit0 Kit puede abrir programas portables de terceros colocados en la carpeta `Apps\`. **Este repositorio y la versión Lite no los incluyen**:
cada programa pertenece a su autor y se rige por su propia licencia, que puede no permitir redistribuirlo. Descárgalos de la web oficial de cada autor,
comprueba su firma y su huella, y copia su carpeta dentro de `Apps\`. Las que falten aparecen en el kit como «No está en la carpeta Apps».

| Herramienta | Para qué sirve | Categoría |
|---|---|---|
| Core Temp | Temperatura individual de cada núcleo de la CPU, carga y frecuencia en tiempo real. | CPU |
| CPU-Z | Modelo exacto de procesador, frecuencias, caché, placa base y módulos de memoria. | CPU |
| HWiNFO | Telemetría completa del hardware y sensores (temperaturas, voltajes, consumo y ventiladores). | CPU |
| HWMonitor | Temperaturas, voltajes y ventiladores en tiempo real con registro de mínimos y máximos. | CPU |
| LibreHardwareMonitor | Sensores en vivo: temperaturas, ventiladores, potencia y voltajes con soporte PawnIO. | CPU |
| CrystalDiskInfo | Estado S.M.A.R.T. de discos: salud, temperatura, sectores reasignados y horas de encendido. | Disco |
| CrystalDiskMark | Mide la velocidad secuencial y aleatoria de lectura y escritura del disco. | Disco |
| HDDScan | Diagnóstico S.M.A.R.T. y escaneo de superficie bloque a bloque para HDD y SSD. | Disco |
| WinDirStat | Mapa visual interactivo del uso del disco clasificado por tipo de archivo. | Disco |
| WizTree | Escáner ultrarrápido MFT que muestra qué archivos y carpetas ocupan más espacio en disco. | Disco |
| FurMark | Prueba de estrés térmico extremo para la tarjeta gráfica (GPU). Vigila las temperaturas. | Estrés |
| OCCT | Suite profesional de estrés para CPU, GPU, VRAM y fuente de alimentación (PSU). | Estrés |
| Prime95 | Tortura de CPU y controlador de memoria para detectar inestabilidad térmica o de voltaje. | Estrés |
| GPU-Z | Especificaciones de la tarjeta gráfica, sensores de temperatura, carga y memoria VRAM. | GPU |
| AdwCleaner | Elimina adware, secuestradores de navegador, barras de herramientas y PUPs. | Malware |
| KVRT | Kaspersky Virus Removal Tool: escáner antimalware profundo sin instalación. | Malware |
| Sophos Virus Removal Tool | Segundo motor antimalware independiente. Se instala en el equipo al abrirlo: desinstálalo al terminar si es de un cliente. | Malware |
| Trellix Stinger | Escáner ligero de amenazas muy extendidas (antes McAfee Stinger), sin instalación. | Malware |
| MemTest64 | Comprobación rápida de errores de direccionamiento y estabilidad en memoria RAM. | Memoria |
| MemTest86 (USB) | Crea un pendrive autoarrancable con MemTest86 (borra el USB) para diagnóstico fuera de Windows. | Memoria |
| TestMem5 | Prueba intensiva de estabilidad de memoria RAM. Ciérrala cuando complete el ciclo. | Memoria |
| CRU | Custom Resolution Utility: edita resoluciones EDID y tasas de refresco del monitor. | Pantalla |
| Monitor Test | Patrones de prueba ligeros para detectar fugas de luz (bleeding) y píxeles atascados. | Pantalla |
| MonTest | Suite PassMark MonitorTest: contraste, uniformidad, convergencia y tiempos de respuesta. | Pantalla |
| Test de teclado (App) | Utilidad de escritorio clásica para verificar códigos de pulsación del teclado. | Periféricos |
| USBDeview | Lista todos los dispositivos USB conectados y los que se conectaron antes. Útil en conflictos de controladores USB o para ver qué pendrives se enchufaron. | Periféricos |
| PhotoRec | Recupera archivos borrados (fotos, documentos, vídeos…) de discos, tarjetas o pendrives, aunque estén dañados. Guarda lo recuperado en OTRA unidad, nunca en la que se quiere recuperar. | Recuperación |
| TestDisk | Recupera particiones perdidas y repara el arranque de un disco. Se usa en una ventana de texto y puede cambiar la tabla de particiones: solo para quien sabe lo que hace. | Recuperación |
| Autoruns | Muestra absolutamente todo lo que arranca con Windows (registro, tareas, servicios, DLLs). | Sistema |
| IP Changer | Cambia la IP, máscara, puerta de enlace y DNS del equipo con perfiles guardados: para conectar a routers o impresoras con IP fija. | Sistema |
| Process Explorer | Muestra todos los procesos con su árbol, uso de recursos y a quién pertenecen. Sirve para investigar un proceso sospechoso o saber qué bloquea un archivo. | Sistema |
| WTools | Latencia DPC, overlay de GPU y utilidades de sistema. Evita su limpieza y reparación de registro en equipos de clientes (su copia del registro falla). | Sistema |
| Rufus | Crea pendrives de arranque con Windows, Linux o herramientas de rescate. Borra todo el contenido del pendrive elegido. | Utilidades |

Esta lista se genera del catálogo de la app; no es una concesión de licencia sobre ninguno de esos programas.
